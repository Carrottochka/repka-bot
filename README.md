# Бот РЕПКА в Telegram

Бот знакомит с приложением и даёт две подсказки, которые уже есть в РЕПКЕ: лунный день и соседей по грядке. Журнал участка в Telegram не ведётся. Ссылка на установку ведёт в RuStore.

## Что умеет

- `/start` — приветствие и кнопки
- «Инструкция» или `/guide` — шаги по разделам приложения
- «Лунный день» или `/calendar` — фаза, знак и совет на сегодня
- «Соседи на грядке» или `/neighbors` — совместимые культуры
- «Что умеет Репка» — коротко о приложении
- «Скачать» — ссылка на карточку в RuStore

Расчёт луны и список соседей повторяют логику Android-приложения. Бот не хранит переписку и не просит личные данные.

## Ролики к инструкции

К уроку можно приложить короткий mp4. Пока файла нет, бот показывает только текст.

Первый, кто отправит ролик, становится автором инструкции. Дальше ролики принимает только он.

1. Напишите боту `/clip seeds_create` (код урока после команды).
2. Следующим сообщением пришлите видео.
3. Откройте этот шаг в «Инструкции»: ролик придёт перед текстом.

Отмена ожидания видео — `/cancel`. Коды уроков бот пришлёт, если написать `/clip` без кода. Файл также можно положить вручную: `telegram-bot/media/guide/seeds_create.mp4`.

Коды раздела «Семена»: `seeds_create`, `seeds_edit`, `seeds_copy`, `seeds_collect`, `seeds_delete`, `seeds_list`, `seeds_search`, `seeds_filters`, `seeds_sort`, `seeds_bulk`, `seeds_folders`, `seeds_card`, `seeds_plant`.

## Как запустить

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Задайте имя, например `РЕПКА`, и username, который заканчивается на `bot`.
3. Скопируйте токен. В папке `telegram-bot` создайте файл `.env`:

```
BOT_TOKEN=сюда-токен-из-botfather
```

4. Установите зависимости и запустите бота (нужен Python 3.9+):

```
cd telegram-bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

Пока это окно открыто, бот отвечает. Для постоянной работы тот же процесс нужно держать на сервере: бот ходит в Telegram сам (long polling), отдельный HTTPS-адрес не нужен.

Проверка справочников без токена:

```
python -m unittest tests.test_bot_content tests.test_guide
```
